# QodeX 2.0 — 7-Figure Redesign Brief
## Reference: Calm × Headspace × Peloton × Duolingo

---

## DESIGN REFERENCES

### Primary References
| App | Element | Why |
|-----|---------|-----|
| **Calm** | Breathing animations, sleep stories | Emotional resonance |
| **Headspace** | Character-led onboarding, structured paths | Trust & guidance |
| **Peloton** | Live energy, instructor cult, leaderboards | Community & status |
| **Duolingo** | Gamification, streaks, dopamine loops | Retention |
| **Loona** | Visual storytelling, premium feel | Aesthetic benchmark |
| **Oura** | Data visualization, insights | Information design |

### Visual Language
- **Motion**: 60fps micro-interactions, physics-based springs
- **Depth**: Layered shadows, glassmorphism, parallax
- **Light**: Dynamic lighting, glow effects, particle systems
- **Sound**: Haptic feedback, subtle audio cues

---

## ONBOARDING: THE "AHA" JOURNEY

### Screen 1: The Breath (0s)
- Full-screen animated gradient (deep purple → cosmic black)
- Central sacred geometry pulsing with user's hypothetical breath
- No text for 3 seconds — pure emotional priming
- Then: "QodeX" fades in, letter by letter

### Screen 2: The Promise (5s)
- "Decode the patterns that shape your life"
- Subtitle: "Used by 50,000+ seekers"
- Social proof: Rotating avatar stack

### Screen 3: The Birth (10s)
- Not a date picker — a **cosmic calendar**
- User swipes through time, stars align
- Haptic feedback on each year
- Dramatic reveal: "March 8, 1990 — a significant date"

### Screen 4: The Revelation (15s)
- **Full-screen number animation**
- Counts up rapidly, slows, lands on Life Path
- Particle explosion in gold
- "You are a Life Path 7"
- "The Seeker" appears with definition
- **This is the hook** — emotional peak

### Screen 5: The Tease (20s)
- "But that's just the beginning..."
- Peek at full chart (blurred, locked)
- "Create your free profile to unlock"

## DASHBOARD: THE DAILY RITUAL

### Morning Entry
- **Time-based greeting**: "Good morning, Seeker"
- **Weather + Qode fusion**: "It's rainy today — perfect for introspection"
- **Daily number card**: Large, tappable, flips for details

### The Orb (Central Navigation)
- Instead of tabs: **floating orb** at bottom
- Expands on tap: radial menu with 5 destinations
- Haptic on each selection

### Personalization Engine
```
User opens app →
  IF morning → Show daily Qode
  IF afternoon → Show community activity
  IF evening → Show reflection prompt
  IF streak at risk → Show streak recovery
```

## CALCULATOR: THE REVEAL

### Input Experience
- **Name entry**: Letters appear as stardust
- **Date selection**: Planetary alignment visualization
- **Calculate button**: Press and hold, fills with energy

### Results Animation
1. Screen darkens
2. Numbers appear as constellations
3. Lines connect — form user's "chart"
4. Each number pulses, reveals meaning
5. **Shareable card** auto-generated

## COMMUNITY: THE CIRCLE

### Visual Design
- Not a list — a **constellation map**
- Each member is a star
- Compatible members glow brighter
- Tap to connect

### Live Sessions
- **Countdown timer**: Large, dramatic
- "Going live in 00:04:32"
- Pre-session: Chat, music, anticipation
- **Shani's entrance**: Special animation

### Mentorship
- **Matching animation**: Two stars connect
- "You and Sarah are 87% compatible"
- Visual path showing shared traits

## GAMIFICATION: THE JOURNEY

### Streak System
- Not just a number — a **flame that grows**
- Miss a day? Flame dims, doesn't die
- Recovery mode: "Rekindle your streak"

### Achievements
- **Badges as constellations**
- Collect them to form patterns
- Rare badges: Animated, 3D

### Leaderboards
- **Seasonal competitions**
- "This week's Seekers"
- Top 3: Special podium animation

## SUBSCRIPTION: THE UPGRADE

### Paywall Design
- Not a list — a **transformation journey**
- Free: "Explorer" (grey, small)
- Seeker: "Initiate" (gold, growing)
- Initiate: "Adept" (purple, glowing)
- Master: "Master" (rainbow, legendary)

### Trial Experience
- **7-day trial as journey**
- Daily unlocks new feature
- Day 7: "You've experienced the power..."

## ANIMATION SPECIFICATIONS

### Micro-interactions
| Element | Trigger | Animation |
|---------|---------|-----------|
| Button | Tap | Scale 0.95, glow, haptic |
| Card | Scroll | Parallax depth |
| Number | Reveal | Count-up, particle burst |
| Avatar | Load | Fade + scale from center |
| Success | Action | Confetti + sound |

### Transitions
- Screen-to-screen: **Shared element transition**
- Modal: **Spring from bottom with blur**
- Loading: **Skeleton + shimmer**

### Physics
- Spring damping: 0.7
- Spring stiffness: 100
- Duration: 0.3-0.5s
