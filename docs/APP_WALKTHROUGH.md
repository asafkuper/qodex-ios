# QodeX App Walkthrough
## Complete User Journey from Download to Daily Use

---

## SCREEN 1: LOGIN / WELCOME

### Visual Description:
- **Background**: Deep cosmic black (#0A0A0F) with subtle sacred geometry patterns
- **Center**: Animated logo with rotating gold rings and hexagon
- **Typography**: "QodeX" in bold white, "INNER CIRCLE" in gold caps below
- **Inputs**: Two dark void input fields for email and password
- **CTA**: Large gold button "Enter the Circle →"

### User Actions:
1. User opens app → sees breathing animation on logo
2. Can log in with existing account OR
3. Tap "Join QodeX" to start onboarding

### Key Design Elements:
- Sacred geometry creates immediate mystical feel
- Gold accents signal premium quality
- No clutter — single focus per screen

## ANIMATION & MICRO-INTERACTIONS

### Breathing Logo (Welcome)
- 3 concentric circles
- Scale 1.0 → 1.1 → 1.0
- Duration: 3 seconds
- Easing: ease-in-out
- Creates calm, meditative feel

### Number Reveal (Calculator)
- Stagger animation: 0.2s delay between cards
- Scale 0.8 → 1.0
- Opacity 0 → 1
- Slight bounce on complete

### Progress Bars
- Smooth fill animation
- Color gradient (gold glow)
- Haptic feedback on milestone

### Card Selection
- Scale 1.0 → 0.98 on press
- Background lightens
- Border highlights

### Streak Celebration
- Confetti particles
- Flame pulse animation
- Number count-up
