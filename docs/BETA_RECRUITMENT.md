# QodeX Beta Program — Recruitment System

## 🎯 Goal
Recruit 100 high-quality beta users for Month 2 testing.

---

## 📋 BETA APPLICATION FORM

### Fields Required

**1. Basic Info**
- Full Name (required)
- Email (required)
- Phone/WhatsApp (optional)
- Age (18+ required)
- Location (timezone for live sessions)

**2. Numerology Experience**
- Have you used numerology before? (Yes/No/A little)
- What interests you about numerology? (text)
- What's your Life Path number? (if known)

**3. App Usage**
- iPhone or Android? (iOS only for beta)
- How did you hear about QodeX?
- Why do you want to join the beta?

**4. Commitment Level**
- Can you attend weekly live sessions? (Yes/Maybe/No)
- Willing to provide feedback? (Yes/No)
- OK with TestFlight beta builds? (Yes/No)

**5. Demographics (Optional)**
- Occupation
- Wellness spending habits
- Other spiritual apps used

---

## ✅ SCREENING CRITERIA

**Auto-accept (Priority 1):**
- iPhone user
- Can attend live sessions
- Willing to give feedback
- Expresses genuine interest

**Accept (Priority 2):**
- iPhone user
- Flexible on live sessions
- Willing to give feedback

**Waitlist:**
- Android users (for future)
- Can't commit to feedback

**Reject:**
- Under 18
- No iPhone and unwilling to borrow
- Spam/bot indicators
