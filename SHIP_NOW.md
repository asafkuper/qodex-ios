## 📦 Archive Process

### Step 1: Open Xcode
```bash
open QodeX.xcodeproj
```

### Step 2: Verify Build Settings
- Target: QodeX iOS
- Minimum iOS: 17.0
- Bundle ID: com.qodex.app
- Version: 1.0.0
- Build: 1

### Step 3: Archive
1. Product → Destination → Any iOS Device (arm64)
2. Product → Archive
3. Wait for build (5-10 minutes)

### Step 4: Upload to App Store Connect
1. Window → Organizer
2. Select latest archive
3. Click "Distribute App"
4. Select "App Store Connect"
5. Select "Upload"
6. Follow prompts (signing, etc.)
